Projects

Project 1: Interactive Audio & Visual

Inspired by lofi and pixel aesthetics, I want to explore sound as a way to create comfort and calm. I designed an interactive bedroom scene where users can click on different cats to play or stop sounds, creating a personalized and immersive sound experience.

Project 2: HyperNarrative

This project creates an interactive experience that explores memory as a fluid and immersive space. Beginning in a state of pressure and urgency, the user moves toward a calmer, blue-toned environment where memories unfold through fragmented text and subtle interactions.

Project 3: Networked Care

This project is called Woven into Light. It is an interactive space for those grieving the loss of a beloved pet. It is mainly a field of softly glowing stars, each holding a personal memory or unspoken message. Entering this shared space, user can find a place to express their own grief, witness and support other people's grief through a gentle, non-verbal interaction.

I used Claude to create a personal homepage inspired by the early 1990s web to see the difference between past and present web experience.

Lightspace

Inspired by the reading by Laural Schwulst, I created this interactive website using Manus, where the visual effects of the landscape will change according to your mood. It embodies Laurel Schwulst’s idea of the website as a living, mutable space rather than a static container of information.

Digital Trace as Presence

Inspired by Molly Soda’s exploration of digital visibility , this website experience examines the function of digital trace as presence. Mimicking an Instagram profile page, each refresh leaves behind a translucent “ghost cursor,” gradually covering the whole page. Here, presence is defined not by what is posted, but by the traces left behind through interaction.

Tidal

This website experience is inspired by Neema Githere’s idea of data healing. Instead of treating users as data to be stored and categorized, the website offers a healing and restorative interaction. There are no like buttons, no follower counts. When users type something personal, the words gently dissolve into water instead of being saved or extracted.

How Are You Arriving

reading by Brandon Gregory argues that accessibility must account for cognitive diversity such as anxiety, and mental fatigue, challengeing the dominance of speed-driven design norms that assume uniform cognitive capacity among users. So during this website experience, the interface acknowledges cognitive fluctuation as normal. Users can select how they are arriving to the webiste, and the system adapts layout density and hierarchy in response.

Activity Tracker

This vibe coding experience is inspired by critiques of predictive algorithms. Users can click anywhere on the screen, but the system only counts clicks within one hidden area, concluding that this area has the most activity. It shows how systems only record what they are directed to observe, while everything else remains invisible.

Behavioral Canvas

Inspired by Olivias' practice of connecting different medias using one interface, I created this drawing interface where every line becomes a behavior instead of an image. Straight lines create rhythm, curves generate motion, and intersections trigger sound. Over time, the system evolves based on how these elements interact.

Thoughts

This semester, vibe coding became one of the most surprising and meaningful parts of my creative process. What stood out to me the most was my “tidal” project. The aesthetic it generated felt unexpectedly refined and unique. I realized that the outcome is deeply tied to the precision of language in the prompt; the more intentional and specific the wording, the more striking and nuanced the result becomes. This shifted how I think about coding, not just as technical execution, but as a form of linguistic and conceptual design. At the same time, readings and discussions made me more critical of the tools I was using. I learned that what websites present is not always neutral or accurate, and even code can carry bias. This reminded me to approach technology with a more questioning mindset. Overall, vibe coding helped me clarify my own direction. I want to create interactive spaces that feel calming and healing, where users can slow down and emotionally connect rather than just consume content.
